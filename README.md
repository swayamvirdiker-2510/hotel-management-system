# Hotel Management System

A simple front-end web application for managing hotel operations, built as a college project.

## About

This project was developed as part of a college submission ("HOTEL MANAGEMENT" report)  Swayam Virdiker, Don Bosco College of Engineering.

## Features

- Browse and view hotel/room information
- Simple, interactive front-end interface
- Client-side interactivity via JavaScript

> Update this list once the code is pushed, to reflect what's actually implemented (e.g. room booking, availability check, admin view, etc).

## Tech Stack

- **HTML** — structure (`index.html`)
- **CSS** — styling (`style.css`)
- **JavaScript** — interactivity (`script.js`)

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/swayamvirdiker-2510/hotel-management-system.git
   ```
2. Open `index.html` in your browser — no build step or server required
